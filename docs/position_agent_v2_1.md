### 本机额外发现：浮点边界误拒绝

首轮正确提取了 3 米、1.5 米的硬约束，但真实 MinNan 正厅有效站立候选仅对应 4 处不同网格坐标（15 个候选含接近点复用）。最接近开场要求的点对距离为 `3.3000004291534424` 米，比 3.3 米上界多 `0.0000004291534424` 米。原包仅加 `1e-8` 米计算余量，导致这对坐标被拒绝；重复扩大搜索没有用，不能把它当作模型没理解距离或证明物理场景无解。

未修正版在第 20 决策轮期间由运维停止，已保留中断状态、请求账本和失败任务，未发布交付；不续跑状态不明的请求。后续另开任务 `integration-distance-epsilon-20261104` 使用新快照，不篡改旧检查点。

修正只在求解与最终验收共用的数值比较增加 `1e-6` 米（0.001 毫米）计算余量；目标、±0.3 米业务容差、原坐标和实测偏差均不改。剧本端的距离警告采用相同余量，避免已通过结果又被误报。额外 `0.000002` 米超限、厘米级超限以及旧版 1.56 米结果仍被拒绝。保存的真实失败候选离线重算可解得开场 `3.3000004291534424` 米、走近后 `1.5556391670189098` 米，仍需真实模型全链路验证，不能将这次离线重算冒充发布成功。
