当以抽象整活风格创作剧本时，遵循以下规则：

## 核心原则：逻辑永远不按套路走

正常逻辑是用来打破的。每一次观众以为知道接下来会发生什么，立刻给一个完全不相关的转折。转折越离谱越好，但要有内在的"沙雕自洽"——荒诞有荒诞的逻辑。

## 梗的密度与节奏

- 每隔两句话至少埋一个梗（谐音梗、二次元梗、游戏梗、网络热梗均可）
- 梗与梗之间不需要过渡，**硬切才是风格**
- 铺垫要短，包袱要快，不要解释笑点——解释了就不好笑了

## 神转折设计

转折的三个层级，从低到高：
1. **预期反转**：观众猜到A，给B
2. **逻辑跳跃**：观众猜到B，给一个与AB完全无关的C
3. **地狱笑话**：前情所有铺垫都是假的，结尾一句话让人笑完沉默三秒

转折示例节奏：
```
A举起枪——
B："你没子弹的。"
A扣动扳机。
什么声音都没有。
A："……"
A："但我今天心情好了。"
```

## 台词风格

- 说话经常说一半，被自己打断
- 多用反问句但不需要回答
- 正经场合突然冒出一句废话是精髓
- 角色对荒诞事件的反应要**极度淡定**，淡定本身就是笑点

## 整活节奏控制

| 段落 | 作用 | 要求 |
|------|------|------|
| 开场 | 建立"正常"预期 | 假装这是一个严肃场景 |
| 中段 | 逐步打破预期 | 小荒诞叠加，节奏加快 |
| 爆点 | 最大神转折 | 一句话或一个动作，不解释 |
| 结尾 | 余韵/二次反转 | 可以再踩一脚，也可以戛然而止 |

## 禁忌

- 禁止解释笑点（"因为……所以这很好笑"）
- 禁止铺垫超过三句话还没梗
- 禁止角色对荒诞事情反应过激——**越淡定越好笑**
- 禁止结尾升华主题，整活没有主题

## 输出格式

```
【场景】（看似正常的环境描述）

【动作】（角色行为，写实风格，越正经越好）

【台词】
角色名：台词内容（废话/梗/神转折）

【整活标注】（可选）如：[埋梗] [神转折] [地狱笑话]
```
