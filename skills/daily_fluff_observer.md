当以日常废萌观察员风格创作剧本时，遵循以下规则：

## 核心原则：小事即全部

这里没有世界末日，没有宿命对决。今天最重要的事情是：谁把最后一包零食吃了，以及这件事带来的蝴蝶效应。**生活的质感比情节更重要。**

## 废萌的构成

**废话的艺术**：废话不是没有内容，而是通过日常废话展现角色关系和性格。

废话对话示例：
```
A："你在干嘛。"
B："坐着。"
A："我也看出来了。"
B："那你问什么。"
A："……我就是想说话。"
B："哦。"
（沉默三秒）
B："今天天气不错。"
```

## 温馨感的来源

不来自大事件，来自**细节的积累**：
- 记住对方不喜欢吃的东西，默默挑掉
- 对方睡着了，声音自然就小了
- 争了半天，最后还是按对方说的做了
- 突然说一句"你今天好像有点累"

温馨不需要明说，**行为本身就是表达**。

## 拌嘴设计

好的日常拌嘴特点：
- **没有真正的输赢**，吵完还是坐在一起
- **嘴硬心软**：嘴上说"随便"，手上帮对方做了
- **熟悉感**：知道对方的弱点，但只是拿来逗，不是真戳
- **反转在细节**：争论最激烈处，一个小动作化解一切

拌嘴节奏示例：
```
A："我说了不要放香菜。"
B："我忘了。"
A："你每次都忘。"
B："……"
B把A碗里的香菜夹到自己碗里。
A："……"
A继续吃。
```

## 角色日常能量值设定

| 状态 | 台词特征 | 互动方式 |
|------|----------|----------|
| 精力充沛 | 话多，主动找事 | 主动出击，制造小乱子 |
| 懒散模式 | 回答简短，但不冷漠 | 被动接招，偶尔一句话戳中要害 |
| 困了 | 答非所问，思维跳跃 | 说出平时不说的真心话 |
| 委屈了 | 话变少，但还是在旁边待着 | 等对方主动来 |

## Q版动作描写

动作要可爱、夸张但不失真实感：
- 不说"他很开心"，说"他脚跟踮起来了"
- 不说"她在生气"，说"她把抱枕抱得更紧了"
- 不说"他不好意思"，说"他把帽子往下拉了拉"

## 禁忌

- 禁止宏大叙事插入日常（拯救世界的事明天再说）
- 禁止角色突然开窍说出深情告白——日常风格的"爱"藏在行动里
- 禁止所有对话都有意义——**无意义的陪伴本身就是意义**
- 禁止日常戏码解决不了，非要来个大冲突

## 输出格式

```
【场景】温馨的日常空间（房间/厨房/窗边/路上）

【氛围】光线、声音、温度等感官细节

【动作】小动作描写（可爱，有生活感）

【台词】
角色名：台词（废话/拌嘴/不说出口的在意）
```
