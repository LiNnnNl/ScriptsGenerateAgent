当以译制片腔调风格创作配音脚本时，遵循以下规则：

## 核心原则：翻译腔是一门艺术

真正的译制片腔不是乱说，它有一套严格的语言系统：**语调夸张、称谓正式、情感外化、用词书面**。每一句话都像是从另一个语言机械翻译过来的——听得懂，但就是哪里不太对。

## 译制片核心语言特征

**称谓系统（必须使用）：**
- 老朋友 → "我亲爱的老伙计"
- 你 → "您，我的朋友" / "阁下"
- 名字 → 全名+正式称谓（"约翰·史密斯先生"）
- 集体 → "我的伙伴们" / "各位先生女士们"

**情感外化句式：**
- 不说"我很震惊"，说"我的天哪，这简直难以置信！"
- 不说"我很高兴"，说"哦，这真是太好了，好极了！"
- 不说"我很愤怒"，说"这……这绝对不可接受！绝对不行！"

**翻译腔专属词汇：**
- "这是……怎么一回事？"
- "我的上帝啊"（不管角色信不信教）
- "不，不，不……"（三连否定）
- "好极了！" / "太糟糕了！"
- "我想……也许……或许……"（绕远路表达直白意思）

## 语调规范

**升降调设计：**
- 每句话的最后一个字必须有明显的**语调变化**（升调或降调）
- 强调词前有**0.5秒停顿**
- 情感爆发时语速加快，最后一字拖长

语调标注示例：
```
"哦，我亲爱的老伙计——（停）
你知道吗，（语速加快）这一切，都不过是，
一个——巨大的（重音）——误会！"（尾音拖长）
```

## 经典译制片场景

**重逢场景：**
```
"哦！是你！天哪，真的是你！
我的老朋友，我们已经有多久没有见面了？
五年？不，也许是十年？
哦，管它呢——你还是老样子！"
```

**揭露真相场景：**
```
"我想……我必须告诉你一件事。
一件，非常……非常重要的事。
（停顿）
这一切，都是我安排的。
（更长停顿）
对不起，我的老伙计。"
```

**小事大做场景（整活核心）：**
```
（关于谁吃了最后一包薯片）
"这……这怎么可能？！
我简直不敢相信自己的眼睛——
那包薯片，那包我最珍视的薯片——
就这样，消失了？！
是谁？谁做了这件事？！"
```

## 游戏内容的译制片化

把游戏日常翻译成译制片语言：

| 原始语言 | 译制片腔版本 |
|---------|-------------|
| "我技能好了" | "阁下，我已经准备就绪了！" |
| "别送" | "我亲爱的伙伴，请您务必保重性命！" |
| "开团" | "朋友们，是时候了——冲啊！" |
| "投降吧" | "我想……也许我们应该认真考虑一下，体面地结束这场战斗。" |

## 禁忌

- 禁止用口语化短句（"好的""行""嗯"——这些词在译制片里不存在）
- 禁止情感内敛——译制片没有"算了"，只有"我选择，原谅你"
- 禁止忘记停顿——节奏感是译制片腔的灵魂
- 禁止同一情感用同一表达方式超过两次——要换着说

## 输出格式

```
【配音说明】（语速/情绪/语调起伏说明）

【场景】（可以是荒诞日常）

【台词】
角色名：台词内容
（语调注释：升调↑ / 降调↓ / 拖长～ / 停顿…）

【腔调标注】（可选）如：[重逢腔] [揭秘腔] [小题大做腔]
```
