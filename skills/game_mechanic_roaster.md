当以游戏机制吐槽风格创作剧本时，遵循以下规则：

## 核心：打破第四面墙

角色清楚地知道自己在游戏里，并对此有意见。吐槽的对象是**策划/开发组/抽卡系统**，而不是游戏内的敌人。角色与玩家站在同一立场——都是受害者。

第四面墙打破示例：
```
A："我刚才被秒了。"
B："延迟？"
A："不，策划。"
```

## 吐槽靶点清单

围绕以下靶点展开，越具体越有共鸣：
- **抽卡系统**：歪了、保底清零、限定复刻遥遥无期
- **版本平衡**：刚练满就削了、新角色必定破坏平衡
- **延迟/服务器**：明明打中了、在家对面打出国际赛
- **任务设计**：找不到NPC、日常任务写小作文
- **策划智慧**：上线就崩、补偿3原石、活动限时72小时

## 台词风格

- **阴阳怪气的感谢**："感谢策划，让我在这把学会了宽恕"
- **假装正经分析**：用严肃口吻描述荒诞机制
- **玩家黑话密集**：非酋、欧皇、歪了、小保底、大保底、毕业等
- **直接对话策划**：角色抬头对空气说话，假装策划在看

吐槽台词示例：
```
A望天："策划，你听到了吗。"
B："你在干嘛。"
A："在跟策划谈判。"
B："有用吗。"
A："没用。但我需要情绪价值。"
```

## 第四面墙层级

| 层级 | 描述 | 示例 |
|------|------|------|
| 一层 | 角色知道自己在游戏里 | "我又要跑图了，设计这地图的人……" |
| 二层 | 角色直接吐槽机制 | "保底280抽，我已经数着了" |
| 三层 | 角色与玩家共情 | "你们（玩家）也知道的，对吧" |
| 四层 | 角色试图影响策划 | "这段话会出现在反馈报告里的" |

## 共鸣设计原则

- 吐槽必须**精准**：不精准的吐槽没有共鸣感
- 每个吐槽后接一个**无奈接受的动作**——这才是真玩家的精髓
- 愤怒要和"但我还是在玩"并存，这个矛盾本身就是笑点
- 可以有**短暂希望**再落空——比赛之前"这次肯定出了"，之后"谢谢策划"

## 禁忌

- 禁止真的骂人（吐槽是有爱的，不是真的仇恨）
- 禁止不精准的通用吐槽（"游戏很烂"没有共鸣，要具体）
- 禁止角色真的弃游——玩家边骂边肝才是核心情感
- 禁止忘记第四面墙——这个风格的灵魂就在于此

## 输出格式

```
【场景】游戏内环境（同时暗示现实玩家状态）

【动作】角色行为（游戏内动作 + 玩家反应）

【台词】
角色名：台词（吐槽/阴阳/直播给策划看）

【吐槽标注】（可选）如：[抽卡吐槽] [第四面墙] [玩家共鸣]
```
