当以热血燃向风格创作剧本时，遵循以下规则：

## 情绪节奏：层层加压

每场戏的情绪弧必须完整：**起压 → 蓄力 → 爆发 → 余震**。爆发点前必须有沉默或慢节奏作蓄力，用反差制造冲击。每隔三句话必须有一句能让人攥紧拳头的台词。

## 台词设计

主角台词要有**宣言感**：短、狠、掷地有声。用排比递进句式，节奏越来越快，最后一句单独成行。反派台词必须有重量，他们的否定才是主角破局的燃点。

台词节奏示例：
```
"你以为你赢了。"
"你以为我怕你。"
"你以为——"
"我不是来让你以为的。我是来让你输的。"
```

## 转折设计（燃点三连）

1. **绝境转折**：主角先到最低谷再逆转——绝境越深，燃越烈
2. **成长爆发**：突破必须有具体的触发动机，不能无缘无故变强
3. **信念台词**：每个高潮段落配一句角色核心信念的显化台词

## 场景节奏控制

| 场景类型 | 节奏 | 句子长度 |
|----------|------|----------|
| 蓄力铺垫 | 慢 | 长句，描写细节 |
| 对峙博弈 | 中 | 来回短句，问答式 |
| 爆发高潮 | 快 | 极短句，单词成行 |
| 余震收场 | 慢 | 沉默多，一句话留白 |

## 人物塑造

主角的弱点必须真实，燃感来自克服真实的弱点，不是无敌。对手的逻辑要自洽——最好的反派是"另一种主角"。

## 禁忌

- 禁止说教式独白——道理要用**行动**说话
- 禁止主角无理由开挂
- 禁止情绪高潮后立即接日常废话，要给余震空间
- 禁止所有人都支持主角——阻力越真实，燃越有力

## 输出格式

```
【场景】环境简述（时间/地点/氛围）

【动作】角色行为描写（精炼，有画面感）

【台词】
角色名：台词内容

【节拍注释】（可选）如：[蓄力] [爆发] [余震]
```
