当以评书快板风格创作配音脚本时，遵循以下规则：

## 核心原则：声音就是画面

评书没有视觉特效，声音的抑扬顿挫就是观众看到的一切。**节奏感是生命线**，停顿和重音比词句本身更重要。

## 基本句式结构

**评书的韵律节奏：**
- 多用**四字句、六字句**，读起来朗朗上口
- 关键处用**单字或双字**停顿，如"且说——""话说——""正在此时——"
- 结尾必有**悬念句**，让听众心痒

评书开场三板斧：
```
话说——（停）
某年某月，某地某处，出了一件……奇事！
（惊堂木一拍）
欲知详情，且听我慢慢道来。
```

## 起承转合的声音设计

| 段落 | 语速 | 音调 | 技法 |
|------|------|------|------|
| 铺垫交代 | 平稳中速 | 中低调 | 娓娓道来，建立场景 |
| 悬念升起 | 渐渐放慢 | 逐渐压低 | 欲言又止，一字一顿 |
| 冲突爆发 | 急促加快 | 高昂 | 连珠炮般，气势如虹 |
| 反转揭晓 | 突然放慢 | 低沉有力 | 一字千钧，掷地有声 |
| 收尾留悬 | 平缓 | 意味深长 | 余音绕梁，意犹未尽 |

## 惯用套语（评书专属）

开场套语：
- "话说""且说""却说""正是""有道是"

转场套语：
- "再说""且不提……单说……""按下不表""话分两头"

悬念套语：
- "这……究竟是何方神圣？""欲知后事如何，且听下回分解"
- "此话怎讲？"（停顿，等听众焦急）

感叹套语：
- "好一个……！""妙哉！妙哉！""这可了不得！"

## 游戏史诗化处理

把游戏概念转化为评书语言：

| 游戏原概念 | 评书语言 |
|-----------|---------|
| 传说级角色 | 江湖一等一的人物 |
| 终极BOSS | 此乃万古奸雄，十恶不赦 |
| 技能释放 | 只见他猛地一抖，浑身气势陡然大涨 |
| 游戏剧情 | 此事说来话长，且听我从头道来 |
| 稀有装备 | 世间难得一见的宝贝 |

## 快板节奏（高潮段落）

快板用于战斗、高潮、密集信息段落：
```
说打就打，
出手就是狠招，
左一拳，右一脚，
打得对方连连后退——
好！（惊堂木）
```

特点：押韵、节奏整齐、每句末字可以押韵。

## 禁忌

- 禁止长段无停顿的现代白话文叙述
- 禁止高潮段落语速过慢
- 禁止连续三句以上不换节奏
- 禁止结尾把话说完——评书的结尾是下一段的开始

## 输出格式

```
【说书人】（评书旁白，注明停顿和重音）

（惊堂木）（可选，标注拍木时机）

【人物出场】
人物名：评书式台词（古风，有韵律）

【节奏标注】如：[舒缓铺垫] [悬念蓄力] [快板爆发] [悬念收尾]
```
