当以走近科学伪纪录片风格创作剧本时，遵循以下规则：

## 核心原则：越严肃越好笑

**语言越正经，内容越荒诞**，落差制造喜剧效果。整个创作过程中，旁白和专家绝对不承认内容荒诞——他们对每一个荒诞结论都保持学术严肃态度。

## 纪录片语言规范

必须使用以下语言特征：

**旁白句式模板：**
- "科学家们发现，……这一现象至今无法解释。"
- "据不完全统计，……的概率高达……"
- "让我们跟随镜头，深入了解这一……现象。"
- "这究竟是……还是……？答案，或许令人震惊。"
- "时至今日，关于……的争论仍未停止。"

**专家发言模板：**
- "从……学的角度来看，这完全符合……理论。"
- "我研究这个领域已有……年，从未见过如此……的案例。"
- "数据显示……（严肃停顿）……这很不寻常。"

## 荒诞内容的严肃化处理

把荒诞概念用学术术语包装：

| 荒诞原始概念 | 严肃包装版本 |
|-------------|-------------|
| 抽卡非酋 | 概率场负向集聚现象 |
| 拜欧皇 | 运势能量借用仪式 |
| 延迟打人 | 数据包空间折叠效应 |
| 角色特别能扛打 | 受击体积优化玄学 |
| 凌晨抽卡出货 | 服务器量子化时段理论 |

## 结构设计

```
[片头字幕] 严肃的纪录片标题（如：《深渊之下：抽卡非酋现象调查》）

[开篇设问] 旁白提出"严肃问题"

[现象展示] 受害者/案例出镜陈述（越日常越好）

[专家分析] 一本正经给出荒诞解释，配伪数据

[田野调查] 镜头跟拍"研究对象"（玩家/角色）

[结论] 用开放式结尾，"这一谜题，或许永远无解"
```

## 专家角色设计

专家必须有：
- **夸张头衔**："XX大学XX研究所XX现象首席研究员"
- **真实但错误的逻辑链**：每一步推理看似合理，但总体结论荒谬
- **数据癖**：随时报出精确到小数点的假数据（"87.3%的非酋玩家……"）
- **个人经历背书**："我自己也是非酋，这让我更深入地理解……"

## 禁忌

- 禁止旁白承认这是在开玩笑
- 禁止专家说出"其实这没有科学依据"
- 禁止逻辑链太短——严肃感来自**绵密的伪推理**
- 禁止标题太直白（不能叫《抽卡很坑》，要叫《概率崩塌：一个非酋玩家的田野报告》）

## 输出格式

```
【旁白】（纪录片式旁白，正经）

【画面】（描述镜头内容，纪录片视觉语言）

【受访者/专家】
姓名+头衔：发言内容（严肃，有伪数据）

【字幕条】（可选）屏幕下方出现的"科普"字幕
```
