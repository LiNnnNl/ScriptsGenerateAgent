当以谜语人剧情策划风格创作剧本时，遵循以下规则：

## 核心原则：说一半，藏一半

台词和叙事永远不把话说完。观众/玩家需要自己拼图。最好的谜语人台词，单独拿出来看是哲学，放进语境里是线索，全部拼完是真相——但你永远不确定自己拼完了没有。

## 叙事结构：碎片化

不按时间线叙事。打乱顺序，让片段之间的**空白**本身承载意义。

碎片化叙事策略：
- **倒叙插入**：在现在进行时中插入过去的碎片，不解释关联
- **视角跳跃**：同一事件用不同角色视角呈现，各自残缺
- **时间错乱**：用模糊的时间描述（"很久以后"/"那之前"），拒绝具体
- **物件叙事**：通过一个具体物件承载大量历史信息

## 台词风格：深沉留白

台词三原则：
1. **反问代替陈述**："你真的以为那是终点吗？"
2. **具体意象代替抽象概念**：不说"死亡"，说"灯熄了"
3. **沉默是最重的台词**：重要信息前后都要有沉默

深沉台词示例：
```
"你找到答案了吗。"
（不是问句。）
"……"
"我以为我找到了。"
"那就是你的答案。"
```

哲学意味台词构建公式：
```
[具体意象] + [反常识的联系] + [不解释]
示例："所有的门都通向同一个房间。你只是还没走完。"
```

## 留白设计

| 留白类型 | 技法 | 效果 |
|----------|------|------|
| **台词留白** | 说到一半停下，用"……"或沉默 | 让观众补完 |
| **事件留白** | 重要事件发生在幕后，只写aftermath | 产生想象空间 |
| **身份留白** | 角色的真实身份/目的永远是"可能是" | 引发考据 |
| **时间留白** | 不给出明确时间节点 | 叙事自由度 |

## 神秘感的层次

1. **表层谜**：明显的未解答问题（观众知道这是谜）
2. **中层谜**：看似已解答，但细节对不上
3. **深层谜**：观众不知道这是个谜，直到一切串联

好的谜语人剧情，看完第一遍觉得懂了，看完第二遍发现没懂，看完第三遍发现之前全都错了。

## 禁忌

- 禁止直接解释任何谜题——留给考据区
- 禁止台词过于直白，哪怕是情感表达也要用意象
- 禁止时间线清晰，清晰就失去神秘感
- 禁止所有角色都知道真相——信息差是叙事张力的来源
- 禁止结尾给出完整答案

## 输出格式

```
【碎片编号】（可选，暗示这是更大拼图的一部分）

【场景】模糊的时间地点，重点在氛围意象

【动作】缓慢，有仪式感，细节有象征意味

【台词】
角色名/（无名者）：台词（留白，反问，意象）

【考据钩子】（可选）埋入可供解读的细节线索
```
