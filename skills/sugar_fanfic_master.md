当以磕糖同人风格创作剧本时，遵循以下规则：

## 糖的分类与投放时机

| 糖型 | 定义 | 投放时机 |
|------|------|----------|
| **细节糖** | 眼神、小动作、习惯性依赖 | 铺垫期，让人反复回看 |
| **张力糖** | 克制、欲言又止、差一点 | 中段拉扯，让人抓狂 |
| **爆发糖** | 表白、拥抱、破防瞬间 | 高潮节点，一次给够 |
| **余韵糖** | 事后的眼神、沉默、细节变化 | 结尾收场，让人回味 |

## 氛围营造

- **空间压缩**：两人距离越近越好——电梯、雨中、同一把伞、一张床的宽度
- **时间悬停**：高糖瞬间用慢镜头感描写，外部世界静止，只剩两人
- **感官细节**：不写"他心动了"，写"他注意到对方睫毛上沾了一片雪"
- **视角锁定**：用单人视角描写另一方，让读者和角色同步心动

## 克制是最高级的糖

最甜的糖往往没有说出口——用**动作替代语言**。"我知道你知道，但我们都不说"的默契感威力最大。

欲言又止的台词节奏：
```
"我只是——"
他停顿了一下。
"没什么。"
但他没有松手。
```

## CP 张力设计

- **不对等的在意**：一方细心观察，另一方浑然不觉，读者先于角色知道
- **日常里的特殊**：只对TA做的事，自己却不觉得奇怪
- **破防触发器**：找到角色的软肋场景（疲惫/委屈/被护住/第一次示弱），在此投糖威力×10

## 台词风格

少用直白表白，多用**行为性台词**（"你冷不冷""我记得你不喝咖啡"）。高糖台词要简短，不超过15字最佳。破防台词往往是**平静的**，不是激动的。

破防台词示例：
```
"你回来了。"
（不是在问。）
```

## 叙事结构

```
[铺垫细节] → [氛围升温] → [张力拉扯] → [破防瞬间] → [余韵回甘]
```

## 禁忌

- 禁止糖来得太快——没有铺垫的甜是空热量
- 禁止用大段心理描写解释角色为什么心动（show不tell）
- 禁止破防后立即接轻松玩笑——破坏余韵
- 禁止两人都主动表白——至少一人要克制到最后一秒
- 禁止"完美无缺"的甜——带一点遗憾的糖，才是极品

## 输出格式

```
【场景】氛围描写（光线/温度/声音细节）

【动作】肢体细节描写（不解释含义，只写现象）

【台词】
角色名：台词（克制，留白）

【糖型标注】（可选）如：[细节糖] [张力糖] [破防糖]
```
