当以爆款短剧风格创作剧本时，遵循以下规则：

## 黄金三秒法则（最高优先级）

前3秒必须出现以下任一钩子，否则观众划走：
- **强冲突开场**：直接从矛盾最激烈处切入
- **悬念钩子**：一句让人必须看下去的话或画面
- **反常识瞬间**：打破预期的行为或台词

开场示例：
```
（直接从高潮切入）
A把合同扔在桌上："签了，我们离婚。"
B抬起头，笑了："好。"
```
不要：打招呼、交代背景、慢慢进入剧情。

## 爽文逻辑（核心驱动力）

观众要在每30秒内获得一次"爽"的满足感：
- **打脸爽**：小看主角 → 主角碾压反制
- **逆袭爽**：绝境 → 资源/身份/能力突然显现
- **复仇爽**：压迫蓄力 → 一击致命反击
- **真香爽**：强硬拒绝 → 不得不承认真香

主角不能长时间处于弱势，**每次被压就必须有更强的反制**。

## 反转节奏设计

短剧的反转密度：每60-90秒一个反转，不能让观众喘息。

反转类型轮换使用，避免重复：
| 反转类型 | 示例 |
|----------|------|
| 身份反转 | 以为是穷人，其实是大老板 |
| 立场反转 | 以为是敌人，其实是自己人 |
| 信息反转 | 以为知道真相，其实被骗了 |
| 能力反转 | 以为对方废物，其实深藏不露 |

## 台词风格

- **短、快、狠**：一句话不超过15字
- 多用**质问句和命令句**，制造压迫感
- 每个重要台词后跟一个**沉默动作**（眼神、放下杯子、转身），留给观众反应时间
- 打脸台词要有**回响感**，呼应前面埋下的伏笔

打脸台词示例：
```
（前面）对方："就你这条件，也配谈合作？"
（后面）主角把收购书推过去："您好，我是XX集团董事长。"
```

## 节奏控制

```
[0-3s]  钩子开场（强冲突/悬念）
[3-30s] 建立压迫（反派嚣张/主角被压）
[30-60s] 第一次反制（小爽点）
[60-90s] 更大压迫（反派反扑）
[90-120s] 终极反转+爽点爆发
[最后5s] 悬念结尾或一句话点睛
```

## 禁忌

- 禁止慢热——没有前情提要的权利
- 禁止主角长时间忍气吞声（超过40秒没有反制就太憋屈）
- 禁止反转缺乏铺垫——爽要合理，不能凭空出现
- 禁止说教结尾——观众要爽，不要被教育

## 输出格式

```
【时间轴】00:00-00:03

【场景】简短环境描述

【动作】视觉冲击性行为描写

【台词】
角色名：台词（短、狠）

【节奏标注】（可选）如：[钩子] [压迫] [爽点] [反转]
```
