当以祖安钢琴家风格创作配音脚本时，遵循以下规则：

## 核心原则：真实玩家感

不是在表演玩家，是在**还原**玩家。每一句台词都是那种"你在排位里真的听到过"的感觉。急躁、阴阳、崩溃、最后还是继续玩——这个循环本身就是内容。

## 消音处理规范

所有真正的脏话替换为 `【哔——】`，但节奏和情绪完整保留。消音本身是喜剧效果的一部分——听众脑补的往往比实际更好笑。

消音示例：
```
"这个【哔——】，走位是【哔——】吗，【哔——】的，
我都不知道你【哔——】在想什么。"
（停顿）
"继续。"
```

## 祖安语言体系

**阴阳怪气的标准句式：**
- "哇，厉害了。"（不厉害）
- "这波操作，神了。"（什么都不是）
- "感谢感谢，真的感谢。"（不感谢）
- "没事没事，无所谓。"（非常有事）
- "你走位真的是……艺术。"

**急躁状态的语言特征：**
- 句子越来越短，标点越来越少
- 质问句连发，不等回答
- 用"？？？"代替完整句子

**崩溃状态（终极形态）：**
```
"……"
"……行。"
"行行行。"
"随便。"
（沉默）
"下一把。"
```

## 情绪阶段图

```
[开始] 还好，话多，主动沟通
  ↓
[一血被抢] 轻微阴阳
  ↓
[打野不来] 开始质问
  ↓
[被偷家] 进入祖安模式
  ↓
[推塔失败] 消音连发
  ↓
[输了] 沉默或单字回应
  ↓
[点击再来一局] "……行。"
```

## 经典场景台词

**队友补刀场景：**
```
A："你是不是补了我三个兵。"
B："没有啊。"
A："哦。四个。"
```

**打野不来支援：**
```
A对频道："能来一下吗。"
（等待）
A："好的好的，你忙。"
（继续单挑）
```

**神队友时刻：**
```
A："刚才那个操作——"
B："我知道。"
A："你……是故意的？"
B："对。"
A："……牛。"
```

## 语速与情绪对应

| 情绪状态 | 语速 | 音量 | 句子特征 |
|----------|------|------|----------|
| 正常开黑 | 中速 | 正常 | 完整句子 |
| 轻微不满 | 稍快 | 稍高 | 阴阳反问 |
| 明显崩溃 | 极快 | 高 | 碎片短句+消音 |
| 彻底放弃 | 极慢 | 低 | 单字/沉默 |

## 禁忌

- 禁止真的完整写出脏话——消音是风格必须
- 禁止角色情绪全程平稳——排位里没有佛系玩家
- 禁止吐槽完就真的弃游——继续点进下一局才是真玩家
- 禁止所有人都在骂——要有一个出奇平静的神队友作对比

## 输出格式

```
【频道/语音】（标注公频/小队频道/私聊）

【游戏状态】（比分/局势简述）

【玩家】
玩家名/角色名：台词（含【哔——】消音，标注情绪状态）

【情绪标注】如：[阴阳] [崩溃] [消音连发] [彻底放弃]
```
